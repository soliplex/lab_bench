# Reporting conventions

Use these when the answer is a monetary total.

- Write the figure with a leading `$`, thousands separators, and exactly two
  decimal places -- for example `$1,234.56`.
- State what the figure covers in the same sentence, so the number is never
  reported bare.
- Report the figure the sandbox actually computed. Do not round it, and do
  not restate it from memory.
